2. **Detected architecture.** Next.js 16 App Router with one direct Google tag configuring GA4 and Ads. No custom event/attribution system or other marketing pixels was detected.
3. **GTM.** Container `GTM-NTF8M2Q9`, globally installed with Next.js `Script` beforeInteractive, a hidden first-authored-body noscript fallback and framework script deduplication. Next.js may insert its own hidden boundary first in serialized HTML.
4. **GA4.** ID `G-CHE056H2KV` is exposed to GTM as `kraftt_ga_id`. Website events enter dataLayer; the GTM event tags must forward them. `kraftt_page_view` is mapped to GA4 page_view. Removed independent gtag to avoid duplicate configuration/pageviews.
5. **Clarity.** Optional loader exists and is inactive because no project ID was provided. Configure strict masking and consent before enabling it; do not additionally install it through GTM.
6. **Business events.** All 15 canonical events implemented: whatsapp_click, phone_click, email_click, contact_form_start, contact_form_submit, book_call_click, pricing_engagement, package_cta_click, audit_start, audit_complete, tool_start, tool_complete, case_study_cta_click, outbound_click, service_cta_click. Context is normalized/allowlisted, stale dataLayer fields are cleared and payloads are capped at 25 parameters.
7. **First touch.** Anonymous local-storage record, retained for 90 days, including initial source/medium/campaign/content/term/referrer/landing path/timestamp. Earliest recorded visit is preserved, including direct/unknown.
8. **Current attribution.** Separate per-tab session-storage record, 30-minute inactivity expiry, updated for a new external acquisition or changed campaign. Normal internal navigation does not overwrite the source/landing page. Interaction refreshes are throttled; storage failure uses in-memory records. This is supplemental context, not GA4's native session definition.
9. **AI referrals.** ChatGPT/OpenAI, Perplexity, Gemini, Copilot and Claude recognized using domain boundaries; Bing chat/Copilot paths classified only when available. Ordinary Bing remains search. Conversation paths, prompts and query strings are not stored as referrers. Referrer-stripped traffic remains direct/unknown.
10. **Service mapping.** Nine requested services plus existing Content/Copywriting and AI Creative mapped to normalized values. Service routes under location/region also work; published contact/audit selections are mapped without free-text capture. See the setup guide's exact mapping.
11. **Forms.** Four existing forms instrumented. Meaningful input starts once per mounted form. Submit fires only after the real existing success check. Synchronous in-flight guards prevent repeated simultaneous requests. Failed responses produce no lead conversion; audit_complete means accepted audit request, not payment or delivered audit.
12. **CTAs/tools.** Delegated tracking covers existing tel/mailto/WhatsApp, free-call/bookings, service/pricing, package/bundle, case-study and other external links. Validated WhatsApp form buttons are tracked explicitly. Tool completion is emitted after a valid result/PDF generation. No tool answers, invoice contents, messages, names, emails, telephone numbers or addresses enter custom events. Secondary contextual events are not additional leads.
